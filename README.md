# セリフスイッチ

演技指示と短いセリフをランダムに組み合わせる、即興ボイスチャレンジ用Webアプリです。PC・スマートフォンのブラウザで利用できます。

## 利用について

声出し練習やシチュエーションボイスの練習、配信・動画のネタなど、ご自由にご利用ください。配信や動画で画面・お題を使っていただいて構いません。事前の許可・利用報告・連絡は不要です。

## 起動・使い方

公開済みのGitHub PagesのURLを開き、1問の制限時間（1〜120秒）と出題回数（1〜100回）を整数で設定して開始します。初期値は5秒・10回です。

演技指示とセリフそれぞれで「男性寄り」「女性寄り」「共通」をON／OFFにできます（初期値はすべてON）。選んだカテゴリから出題し、表示件数やトップのお題の例にも反映します。演技指示・セリフともに1カテゴリ以上、有効なお題が1件以上必要です。カテゴリは表現の目安で、どなたでも自由に演じられます。お題の例はページを開いたとき、カテゴリを変えたとき、設定画面へ戻ったときにランダムに更新されます。

設定画面の「効果音」で音のON／OFFを切り替えられます（初期値はOFF）。ONにすると、開始時とお題が切り替わったときに効果音が鳴ります。タブを離れている間や、戻った際の追従では鳴りません。音を再生できない場合は通知してOFFにし、チャレンジを続けます。

開始直後に1問目が表示され、制限時間ごとに次のお題へ進みます。同じ組み合わせの連続出題は、組み合わせが2つ以上あれば避けます。終了後は出題順の履歴を確認でき、途中終了した場合もそこまでの履歴を表示します。「もう一度挑戦する」で設定画面に戻れます。

タブを離れても時間は進みます。画面の更新が遅れた場合は実経過時間に追従し、その間のお題も予定順の履歴に含めます。チャレンジ中は画面を開いたままお楽しみください。

ローカルでは、リポジトリのルートでPython 3のHTTPサーバーを起動し、`http://localhost:8000/` を開きます。

```powershell
py -m http.server 8000
```

## データの追加

次のUTF-8テキストファイルを、1行につき1項目で編集します。

| カテゴリ | 演技指示 | セリフ |
| --- | --- | --- |
| 男性寄り | `data/directions/male.txt` | `data/lines/male.txt` |
| 女性寄り | `data/directions/female.txt` | `data/lines/female.txt` |
| 共通 | `data/directions/common.txt` | `data/lines/common.txt` |

性別を問わず自然に演じられる表現は共通にまとめています。男女別のファイルには、兄・姉、彼氏・彼女など、役柄や言い回しに性別が関わるものだけを入れます。一人称を付け足して分けたり、カテゴリの件数をそろえたりする必要はありません。

初期データは演技指示・セリフ各100種類です。空行と前後の空白は無視し、選択したカテゴリを合わせて完全に同じ項目は1件として扱います。「優しく」と「優しい声で」のように表現が異なれば別の項目です。カテゴリ単体のファイルは空でも構いません。

GitHub上で `data/` のファイルを編集・コミットして更新できます。6ファイルのいずれかの読み込みに失敗した場合や、10秒以内に読み込めない場合は日本語のエラーが表示されます。データや接続を確認し、「もう一度読み込む」で再試行してください。
